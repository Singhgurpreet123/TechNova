# TechNova Solutions — Corporate Business Website

A modern, responsive, and production-quality corporate website designed for **TechNova Solutions** — an enterprise IT Services, AI Solutions, Software Engineering, and Cloud Infrastructure company.

---

## 🌟 Project Overview

**TechNova Solutions** is built with a mobile-first, performance-optimized, modern aesthetic featuring soft shadows, gradient accents, rounded corners, sticky blurred glass navigation, animated scroll stats counters, Bootstrap 5 responsive grid system, and vanilla JavaScript form validation and dynamic modals.

---

## ✨ Features

- **Responsive Sticky Navigation**: Blur-glass backdrop with active scroll section highlight and auto-closing mobile menu.
- **Section 1 — Hero Section**: Full-width header with tech background, compelling call-to-action buttons, and floating stats badge.
- **Section 2 — About Company**: Experience counter badge, key company pillars, and modal trigger for expanded history.
- **Section 3 — Mission & Vision**: Custom cards highlighting Innovation, Quality, AI Leadership, and Digital Transformation.
- **Section 4 — Services**: 6 interactive service cards with hover scale animations and detailed modal overlays.
- **Section 5 — Why Choose Us**: 6 feature cards highlighting experienced team, affordable pricing, fast delivery, and 24/7 support.
- **Section 6 — Products / Solutions**: 6 turnkey enterprise software product cards with images and feature breakdowns.
- **Section 7 — Statistics / Achievements**: JavaScript animated counter numbers triggered on scroll.
- **Section 8 — Testimonials**: Customer review cards with star ratings, avatars, and quotes.
- **Section 9 — Team Members**: Profile cards for leadership with social media links.
- **Section 10 — Pricing Plans**: 3 flexible membership cards featuring the highlighted "Most Popular" Professional Plan.
- **Section 11 — FAQ**: Accordion with 6 essential FAQs (one open at a time).
- **Section 12 — Contact Form**: Client-side validated contact form with full name, email, phone, subject, and message fields + office details card.
- **Section 13 — Newsletter Subscription**: Real-time validated email subscription input with toast notification feedback.
- **Section 14 — Google Maps**: Embedded responsive location map.
- **Section 15 — Footer**: Comprehensive footer with quick links, service catalog, contact shortcuts, social icons, and floating back-to-top button.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for high SEO compatibility and accessibility.
- **CSS3**: Custom CSS variables, flexbox/grid layouts, smooth animations, and soft shadows.
- **JavaScript (Vanilla)**: Lightweight interactive script handling scroll observers, modal rendering, counter animations, and form validation.
- **Bootstrap 5 (v5.3.3)**: Responsive grid layout, modals, navigation bar, and accordion components.
- **Font Awesome 6 (v6.5.1)**: Modern vector icons.
- **Google Fonts (Poppins)**: Clean typography scale.

## 🚀 How to Run

1. Clone or download the repository files.
2. Open `index.html` directly in any modern web browser (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge).
3. Alternatively, serve using any standard static server or Vite.

```bash
# Example with static preview / Vite
npm run dev
```
